# Périmètre de la version 0.4.1

Cette liste conserve le périmètre et les vérifications de la 0.4.1. Les éléments cochés sont intégrés ; les limites de validation restante sont indiquées explicitement.

- [x] **Preset du portail par défaut** : inclure la correction déjà préparée localement pour conserver le widget Emby/Jellyfin sous son application et le widget Seerr sous Seerr, avec les mêmes largeurs, même lorsque Tracearr est activé. Placer le widget Tracearr sur une ligne séparée, pleine largeur. Préserver les portails déjà personnalisés.
- [x] **Captcha** : centrer horizontalement le captcha sur les deux formulaires, connexion et demande de réinitialisation du mot de passe. Il est actuellement aligné à gauche.
- [x] **Modèle de mail d'invitation par défaut** : ajouter une présentation des avantages de Gatearr pour l'utilisateur :
  - une plateforme unique pour accéder à ses services ;
  - un mot de passe commun à Gatearr et au compte Emby/Jellyfin, que l'utilisateur peut modifier et réinitialiser lui-même ;
  - des guides pour connecter Emby/Jellyfin sur ses différents appareils.

Le texte du mail devra rester cohérent avec les services configurés, sans modifier les modèles déjà personnalisés par l'administrateur.
