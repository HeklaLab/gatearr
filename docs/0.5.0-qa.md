# Gatearr 0.5.0 — desktop functional validation

Review completed 29 October 2026. The validation below was recorded before release publication.

## Page-directory actions

Rows now share compact icon buttons of the same height: Edit guide where applicable; joined Edit/View controls; joined Publish/Published and Hide/Hidden controls; Delete. ## Functional laboratory

A disposable database and real local HTTP/SMTP processes were used, separate from the presentation demo. All **19 scenarios passed**:

- Fresh database migrations, English-only installation and native Emby administrator login.
- Configuration and authenticated connection probes for Emby, Seerr, Radarr, Sonarr, Bazarr, Tracearr and Tdarr.
- Administrator/member tool separation and denied member access to administration.
- Protected Radarr, Sonarr and Bazarr proxies, authenticated upstream requests and no API secret in the returned browser HTML.
- Tdarr HTML, runtime configuration, JavaScript and CSS through the protected proxy with correct content types.
- Historical laboratory scenario: Tracearr member access granted/revoked. Superseded by the final administrator-only contract verified below; stored member grants no longer authorize its interface.
- Group-only page visibility and navigation, including removal of membership and no administrator bypass of explicit page audiences.
- Disabling all six optional integrations while their upstream is unreachable.
- Draft → published → hidden → deleted → restored draft, with public URL visibility following state.
- Existing-page duplicate-address validation.
- **15 actual SMTP messages captured locally**: five purposes (invite, reset, verify, email change, password change), each with plain text, logo or centred multiline content. HTML MIME, expanded image URLs and alignment were inspected. No message was sent to an external mail server.

Some fixture permissions/group memberships were set directly in the isolated database; access and revocation were then exercised through real HTTP requests. This laboratory complements automated tests of the corresponding admin endpoints.

## Defect found and corrected

Changing an existing page to an address already in use still produced the generic “Invalid value” response. Creation already had an actionable message. The save and database-conflict paths now return “This page address is already in use. Choose another address.” A regression test first reproduced the failure, then passed after the fix; the isolated HTTP scenario also passed.

## Scope and limits

The automated suite covers page/block scopes, account functions and defaults, drafts/publication, audiences, guide publication/navigation, system forms, mail rendering, authentication and integrations. Browser checks supplement these tests for layout and interaction.

Simulators validate Gatearr's behavior against their implemented API contracts. They do not establish compatibility with every real third-party version, Docker network or production reverse proxy. SMTP capture proves local composition and transport, not remote inbox delivery. The reporter's exact Logo-only failure in issue #10 has not been reproduced here; it still needs confirmation on that installation. CAPTCHA preview was checked as a representation, not a live provider challenge. No claim of an absolute absence of bugs is made.

### Defects found and corrected

1. Page actions retained desktop widths, squeezing titles and guide URLs into narrow vertical strips. Narrow layouts now put readable names above wrapping, reachable action groups.
2. Translation filters retained three minimum-width columns. They now stack on narrow screens; the search/count row wraps cleanly.
3. At 320 px, an individual Seerr effective-permission badge could force horizontal overflow. The status now sits under the label, with the switch in its own fixed-width column.
4. Guest header controls overlapped at 320 px. The appearance/language menu uses a compact icon while retaining its accessible name; the unnecessary final divider is removed.
5. Guide step instructions used a different text toolbar. Page text, accordion answers and guide steps now use the same formatting component and icon styles; guide/text alignment remains available, while accordion answers retain their intentionally smaller option set.
6. Shared-header accessible names were missing from the customizable public-label inventory. The inventory generator now reads Jinja literals inside quoted HTML attributes, including the header templates. All 201 catalogued public labels have values in all 21 bundled languages.
7. “Bulleted list” was still English in 19 non-English catalogues. Those tooltips now use customary formatting terminology. Corrected Chinese Bold from a literal adjective to 粗体, and refined related Korean, Czech and Turkish toolbar wording. No extra languages were enabled at installation.
